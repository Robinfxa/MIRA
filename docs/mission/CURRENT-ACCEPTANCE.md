# 当前交付验收与缺口

核对日期：2026-10-07。当前完整源码包已整合2012基线、图片审核、自然互动和默认同Wi-Fi免配对三项修补，无需再叠补丁；另提供常用启动入口、非秘密模板和首次使用说明，原5张开发图及来源保留。历史证据、离线检查与最终包核验见[提交版本核验](../submission/VERIFICATION.md)。下面是验收口径，不因实现文件存在就标为通过。

## 当前合同

- 默认`luna_tools`是原生工具协议名，对话模型由操作者选择；`sh scripts/start`的真实预设沿用用户原命令：`gpt-6.1-sol --service-tier fast`、语音/剧情/图片、独立图片审核`gpt-6-luna`。首次明确选择，已有配置不覆盖，默认MIRA登录和原ADC保持。默认不构造JEV，不自动切付费API、换模型或重试。
- 普通输入/回复级打断保留已接受后台图任务和真正呈现的当前赠照邀请，同时取消旧回复及未呈现的旧邀请。图片实际显示回执后，才允许一次空闲时的自然完成续答；它计入模型/TTS预算。精确取消仍只影响指定图/任务，全局Stop和关闭阻止旧输出复活。
- 夏禾当前确认或主动身份询问的明确答复先走实际相认，再于同一真实续答说作者共同往事并发出一次邀请；一次接受应实际赠照，不以预览代替交付，不重复要求接受。合成工具轨迹不保证真实模型每次选择或措辞正确。
- 订阅文字、本地持续监听上限和共享STT请求次数默认是真正`None`；无需`--local-unlimited`。显式有限参数仍生效。TTS仍默认20次/每次30秒，单STT RPC120秒，图片仍1任务/一次生成/至多一次读图，API仍20次生成/20轮；供应商配额、费用、时限、并发、背压和取消不解除。
- 默认barge-in，明确保守选择保持；静默收尾是音量/时间启发式，不等于说话人识别、可靠回声消除或语义理解“已说完”。真实完整声尾与插话仍需用户设备验收。
- 普通`serve`默认选择唯一可确认的物理私网IPv4并免配对开放LAN，歧义时`WARNING`并仅保本机；可显式`--private-bind 192.168.2.13`或`--loopback-only`。Mac的127.0.0.1保留原语音；手机HTTP的后端禁用STT/TTS，手机语音须已有可信HTTPS。16个临时浏览器会话是资源上限，所有入口共享原provider与预算。可选人工配对需`--require-device-pairing`、私密目录及精确origin，HTTP配对同样无语音。
- `--story`是临时作者剧情。记忆、会话档案和角色checkpoint仍各自显式启用/授权/配对，默认不自动录入、抽取或学习人格；持久库保持本机原边界，LAN只支持独立临时会话。

## 明确能力缺口

本地快照、参考素材和当前外观状态不等于对话模型实际看图。独立像素审核主要证明合格和绑定，不能推断完整画面描述已交给角色；完成句不从生成brief编造月亮/构图等观察，也不自动扩大PNG外传用途。未实现或未验证的视觉消费继续列缺口。

用户已经确认基本聊天、固定照片和一次真实新图展示及主动通知。演示视频随邮件另附（用户已录制，本包未包含且未代验）。完整声音/字幕/打断、模型口吻稳定性、手机HTTPS/麦克风和录像内容仍需同版本核对；已有局部实机观察不等于所有设备、所有回合均已验收。操作顺序见[录制指南](../development/DEMO-RECORDING.md)。

2012的13-lane发布与后续修补影响面证据分别保留。LAN最后汇总在providers约98%时中断，恢复十个已成功检查块，仅补跑providers（4523项通过）；独立离线验收不等于重新完整release或实机验收。包内有同版预编译前端，不含依赖环境；全新安装≤15分钟仍未计时。

口型同步、自动VAD/附和区分/回声消除、特定生成媒体和大量工程扩展是原PDF可选；完整长期记忆不是原PDF硬要求。但用户后来明确追加的图片、连续语音、故事与角色要求仍保留，不能用“可选”撤销。
