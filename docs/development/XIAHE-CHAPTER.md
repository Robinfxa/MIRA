# 夏禾相认与赠照章节

这是一个有限的角色扮演章节。你扮演夏禾；没有另一个夏禾 NPC 到场。MIRA 在你明确表明之前没有认出你。相认只影响当前虚构剧情，不是现实身份认证，也不改变用户记忆的读取范围。

## 启动

在新版项目根目录，复用已有 MIRA 登录和私密配置。沿用原来较小的服务预算；下面不启用新图片生成：

```sh
PYTHONPATH=apps/api/src .venv/bin/python tools/live_provider.py serve \
  --provider chatgpt_subscription --model gpt-6-luna \
  --env-file .env --authorize-provider-data --story
```

要继续使用已授权的 Google 语音，可向同一命令追加原先的 `--voice`、`--adc-file`、`--authorize-google-voice-data-and-spend` 和原有次数/时长参数。不要为此重登、复制认证或改写存档。默认 `code-native-review` 支持本章演出；`static-pixi` 保留为旧画面回退，不宣称支持相认反应。

`--story` 不启用自由生图。新图依旧需要原有独立图片数据与用量许可。固定灯塔照片不新增图片服务调用。已有本地故事数据库只有在原先明确配置了故事保存时才使用；默认内存会话不能承诺重启后保留进度。

## 可以这样聊

这些是自然对话示例，不是强制口令，也不用逐字照念。

1. 先以陌生人身份打招呼、聊雨或摄影。她不应提前把你当夏禾。
2. 明确表明身份，例如“我是夏禾，好久不见，你还记得我吗？”相认演出成功后，关系提示才更新。
3. 问起之前一起挑照片的事。三段作者旧事分别涉及桌上的试印、独自海边旅行后的电子照片、被反复推迟的纸样；每轮可以聊一个细节，也可以岔开话题。
4. 聊到为何一直没送出那张纸质照片。她可以自然说出约定与犹豫，不应朗读来源字段、素材编号或“你正在扮演”等制作说明。
5. 请求看看照片。必须真的显示或确认仍显示着先前看过的同一张图。早先已经看过不要求假装再加载一次，也不等于已经赠送。
6. 她提出把照片留给你时，页面显示独立邀请。可以在对话中接受/拒绝，也可以点击“收下照片”或“暂时不收”。按钮绑定当前邀请，不再增加一次模型调用去判断按钮含义。
7. 接受后会有屏内递出与收下状态；成功呈现回执才把本章记为完成。这证明软件演出完成，不代表现实世界物品已交付。

看窗外与换衣服是可选支线，可以穿雨衣后再看窗景，也可以先看窗景再换衣服。拒绝、聊天跑题或暂不收下不会扣关系，也不会阻止普通聊天。全局 Stop 会撤销正在进行的演出与旧邀请按钮；之后明确重新邀请/继续即可，不需要删除存档。更正自己不是夏禾或退出角色扮演后，不再按旧友身份续演。

## 事实与验证边界

- 相认前：夏禾的过去只是作者设定，不能当作当前陌生人与 MIRA 的共同经历。
- 相认后：旧友故事可自然用“我们”讲述，但内部仍标为虚构作者往事。
- 看过照片、邀请赠予、收下照片是三件独立的事。
- 失败、取消或没有收到对应呈现回执的演出不写成完成。
- 当前实现可离线验证协议、编译前端、状态、回执和本地保存。真实模型选择、设备动画与完整语音仍需在同版本实际运行中验收；测试中的合成回复不能证明自然语言每次都会选中同一个节点。

默认每进程 20 次模型请求、20 轮。普通模型回答通常一次请求；固定照片工具可能包含一次选择和一次续答。章末按钮不调用模型，但仍属于有限会话输入。限额到达时不会自动重试或改走付费 API。
