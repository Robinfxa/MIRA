# MIRA 人工浏览器／设备走查（待用户运行）

仅适用于已核验的 `20261003T1756Z-completed-slices`。这是固定离线排练的人工听看清单，不是完整产品验收：声音为预录 Flite 合成英文，配双语字幕和原创插画；没有实时模型、真实麦克风/STT、可用 Gemini TTS 或 live 闭环。自动化/DOM结果不能代替人工观察。

## 约 4 分钟

**启动：** 用户自行在自己的电脑、该核验源码上运行。要求 Python 3.11–3.13、Node.js 22.12+ 和锁定依赖；缺依赖时脚本不会安装，如用户选择准备则执行 `python3 tools/bootstrap.py`（需包注册表）。运行 `sh scripts/dev --profile rehearsal`，同一台电脑打开 `http://127.0.0.1:8000`。无需 `.env` 或 API key；本清单不授权安装、部署或真实服务调用。

1. **0:00–0:30 就绪：** 确认 `OFFLINE · 固定互动排练`、连接正常、麦克风关闭。记源码 commit；无 Git 快照则记快照名和 `capture-manifest.json` SHA-256，以及浏览器/版本、电脑/系统、时间。
2. **0:30–1:00 问候／拒拍：** 点「你好」和「先放下相机吧」（口令「不要拍我」）；应有问候、表情变化和相机放低，不申请相机/麦克风权限。
3. **1:00–1:45 照片／历史：** 点「给我看看你的旅行」，等插画、字幕、声音实际呈现；再点「照片里有什么」，回应应提到雨后海岸与灯塔。仅在确实呈现后才记为已看见。
4. **1:45–2:40 Stop：** 点「讲讲旅途」，语音播放中点「停止回应」；核对声音/字幕停止、已呈现插画保留，记录可听尾音时长。此为预录音频打断，不代表实时 TTS。
5. **2:40–3:15 新输入：** 按住「按住演练输入 · 不录音」，确认 listening 后松开；它只发送固定口令「照片里有什么」，不采集/识别麦克风。
6. **3:15–4:00 故障恢复：** 点「一起听会儿雨」「暖灯」「测试一次失败」，确认失败有提示；再点「你好」确认可恢复。记实际显示的错误码/诊断 ID；无则记“未显示”。

**最小记录：** 每步 `pass / fail / blocked / not_run`；实际所见所闻、字幕/首音时间、Stop 尾音、新输入是否成功、可见错误/诊断 ID；标明人工浏览器/扬声器观察。默认不开原始音频/原文录制，本快照无原始音频录制功能；不要提交含密钥或私人内容的截图。

## 真机／live（待准入）

本机只监听 `127.0.0.1:8000`；手机不能自动访问另一台电脑/云端的 localhost，桌面窄屏不算真机。真手机测试须等**另行批准的受支持设备访问/托管路径**；之前保持 `pending`，不可改端口、开隧道、公开托管或绕过网络限制。

真实 **STT → 决策 → generation → JEV → TTS** 未准入：中文 JEV 校准未完成、所选 TTS 无可用音频、live 工厂关闭。实现、质量/安全审查及所需授权齐备后另立验收；合成音频、英文合成样本 STT、结构化候选与离线测试都不能替代。
