# 连续自然对话：启动与设备验收

本页用于1444之后、包含本地静默分句的候选。准确包含范围和验证结果以同包START-HERE为准；1325是手动发送，1444的自动分句仍依赖供应商活动结束或其偏移证据。本候选增加独立的采集端静默信号。软件测试不代表Google端点质量、耳机/扬声器或手机已经通过。

## 沿用已有登录和配置

在新源码目录准备该版本的依赖，保留旧目录。产品入口是`tools/live_provider.py`，不需要Codex CLI、native二进制或admission文件。已有独立MIRA登录继续使用原存储；原命令如带`--auth-store`，继续指向同一处，不复制认证文件。

环境文件可以继续通过现有绝对路径引用，包括旧项目里的私密文件。当前直连入口支持项目内环境文件；它须是本人拥有、仅本人可读写的普通文件。不要把文件内容或认证缓存发给别人，也不要source整份.env。完整准备步骤见[直连说明](DIRECT_PROVIDER_QUICKSTART.md)。

下面沿用已有的订阅模型；识别次数/聆听默认不限，合成仍用显式较小验收参数。变量代表用户自己已经配置好的文件绝对路径；启动不是零费用离线演练。

```sh
PYTHONPATH=apps/api/src .venv/bin/python tools/live_provider.py serve \
  --provider chatgpt_subscription --model gpt-6-luna \
  --env-file "$MIRA_ENV_ABSOLUTE" --authorize-provider-data \
  --voice --adc-file "$GOOGLE_ADC_ABSOLUTE" \
  --authorize-google-voice-data-and-spend \
  --tts-requests 4 --stt-max-seconds 60 --tts-max-seconds 10 \
  --story --character-renderer code-native-review
```

若复用已有兼容Python环境，可把`.venv/bin/python`直接替换为其绝对解释器路径；`live_provider.py`没有`--python`参数。新源码目录仍需Node锁依赖，不搬迁旧venv。纯声明检查可把`serve`改为`check`，不会新建登录、调用模型或打开麦克风。

`--story`明确加载作者剧情和第一人称背景，普通闲聊仍可停留，不强迫推进。持久用户记忆和checkpoint各有独立配置/同意，本命令不自动启用它们。

## 实际交互

1. 打开本机页面，先确认服务已连接；页面加载不会自动采集。
2. 点击“开始自然对话”，由浏览器处理麦克风权限。静音期间继续聆听；临时文字只作预览，不逐字调用语言模型。
3. 本地采集观察到有效说话后，默认约700毫秒安静便请求收齐最终转写，不必先等Google的活动结束事件。安静时长是可配置的音量启发式；它不证明语义说完。收尾有期限，只有合格最终转写才会自动提交一次，临时文字不会逐字触发模型。页面分别显示聆听、识别中、发送中和已发送，手动发送保留为回退入口。
4. Mira回应时，“打断回应，继续听我说”只中断回复，保持麦克风；下一段补充会关联被打断的请求。原输入和已经呈现的历史保留，未播完的生成稿另标成草稿，不当作听见的事实。普通文字新请求保持独立；新话题不应机械拼接旧意图。全局停止和关闭会释放麦克风。当前默认“语音插话开启（建议耳机）”，连续约160毫秒的新声音活动可尝试本地打断，但没有声学说话人识别，也不证明耳机已连接或回声已消除。
5. 默认模式中，与软件播放重叠的语音仍会在正常安静和合格最终转写后自动发送。早期能量检测未触发或提前打断失败，不会仅因重叠而改为手动；发送前再次尝试本地停止旧回复。同一句的轻声开头、内部停顿和完整补充保留，确切原请求关联不靠关键词。显式保守模式才要求重叠文字人工核对。已消费区间、同句新修订、仍在继续说话或已被新请求取代的来源继续隔离；不能据并行采集和播放声称回声已解决。

新客户端显式选择本地静默分句；旧客户端的供应商活动/偏移策略仍保持兼容。在新模式中，供应商END不会抢先自动提交。静默触发后只收齐该音频边界内的最终转写；继续说话会取消尚未收尾的边界，已收尾后的新增语音和晚到修订按各自身份保留，不重复发送。缺最终转写或排空超时会给出可恢复的可见状态，不能一直等待。

回复语音在首次派发前等待本地安静，后续PCM仍进入同一个连续播放队列，不在每小块间重新等待，也不增加TTS调用。等待/下载首包并不等于已经播放。参数与范围见[有限端点策略](NATURAL_LISTENING_POLICY.md)。不靠标点单独触发，也不由JEV审批用户是否能说话。

明确本地打断造成的同轮音频中止会显示“已打断回应，正在继续听你说”，不会反复报成语音故障。后台中止事实和诊断保留；只有与本地打断身份匹配的状态如此显示，意外中断、传输失败和新一轮错误仍会提示。

## 次数、时长和停止

- PTT与连续识别共享`--stt-requests`进程计数，每个识别RPC，包括续开的子流，都占一次；失败/取消/未知结果不退款。默认不设置本机次数上限，后台仍如实记录共享计数；仅显式有限额度会在页面显示剩余次数。
- 默认lease没有累计时长/样本上限。每个RPC保留有限时长并接续，不把轮转当成人已说完；如主动设置总时长，不因续流重置。输入在收尾期间仍有明确缓冲上限；排空超时、缓冲或次数到限时，显示结束并保留已观察的有界文字。重新开麦需要新手势。
- 这些数量不是美元限额；静音采集也可能被服务计费。进程重启会重置本地计数，不重置真实账单。
- 本例TTS上限仍10秒，没有随修复加长。较长回复可能达到这个上限；不要把真实截断未经诊断就归于文字分块或播放队列。

## 同版本设备验收

建议先用原参数和原问题，避免同时改变声线或时长，让前后观察可比较。

- 一句短话后安静，核对只自动发送一次；记录等待和显示，不把`is_final`或标点当人工通过依据。
- 试一次轻声和有低背景声的停顿；700毫秒是起点，可用`--listen-silence-ms 900`调整，范围250–2000毫秒。不要通过提高请求次数掩盖分句问题。
- 连续第二句，确认上一句不会重复，新句不被上一段保留文字污染。
- 听一份完整回复，检查字幕与音频是否都到结尾；软件样本回执不等于物理听见。
- 回复中使用明确打断按钮，再补充一个条件；确认新回应考虑原请求和补充，旧尾音不会复活，也不会声称未播完的内容已经听完。另验全局Stop后麦克风释放，普通文字仍可发送。
- 语音插话开启时，试一次“等一下，等一下”或轻声起头后补充完整条件；同一句不应因为开头较轻或短暂停顿而再次要求手动发送。若原回复已被另一条文字请求取代，旧插话应保留供核对，不能自动打断或附到新请求。
- 测一次到限、权限拒绝或断开后的恢复，确认已收到的转写/草稿仍可核对；不要重复不确定的已发送请求。
- 记录浏览器/设备、具体步骤、界面安全错误码与诊断编号。没有实际执行的项目标not_run，不分享headers、认证文件或原始provider正文。

支持路径的软件合成检查不覆盖真实声学回声、Google识别准确率、移动端软键盘或同版本3–5分钟实录。历史手动流程保留在[旧记录](history/CONTINUOUS_LISTENING_MANUAL_20261005_1325.md)，不能作为本版启动步骤。

## 麦克风恢复切片

ready前的音频暂存不会一次冲入WebSocket，改为按序有界发送，endpoint/cancel保持同一采样边界。识别请求排空/重开不会停止或重新申请麦克风；真正达到时长、样本、排队、请求限额才会可见停止。播放时纯安静/低底噪不污染下一句，默认模式的有意义声音重叠继续正常分句提交；显式保守模式保留人工核对。不声称识别人声或消除声学回声。意外下游交付失败仅给安全阶段、序号和样本计数，不保存原始音频/文本/异常。

不带显式限额时，共享STT次数和累计聆听默认不限；TTS仍20次/每次30秒。输入120秒是每个RPC的轮转边界，麦克风与整句转写继续。上例主动设置TTS4次/10秒和每RPC60秒，不设置累计STT预算。Google识别会持续计费，直到用户Stop或供应商限制/故障终止。

## 默认语音插话（本候选）

页面默认选择“语音插话开启（建议耳机）”。新版初始化会覆盖未经明确选择标记的旧表单值；在新版手动选择保守模式后才会保留该偏好。页面加载和选择选项不打开麦克风；仍需点击开始及浏览器允许。需要逐段核对播放重叠时可选择“保守模式（重叠语音手动确认）”；聆听中的设置固定，切换须先停止再开始。底层兼容值 `headphones` 只表示功能开启，不表示程序检测了设备或用户声源。

既有探测器以连续2560个16 kHz样本（160毫秒）确认声音活动，持续3200个低音量样本（200毫秒）后才可再次触发。短声、迟到或畸形采集不会开启自动插话。浏览器AEC支持与报告仅作为状态显示，不能证明回声已经消除；没有AEC时，持续噪声或播放回声仍可能触发。

若三次自动尝试发生在两秒采集时间内，会显示“短时间内连续触发，自动插话已暂停”，原打断按钮显示“恢复语音插话，继续听我说”。点击仍会先打断当前回复，再在同一麦克风监听中恢复自动插话；不会重复提交已消费的旧补充、扩大预算或修复无效采集。默认的安静分句仍保持可用。正常间隔的多次插话没有次数上限，仍服从供应商限制与主动配置的有限值。这只是快速重复触发保护，不能消除较慢的声学回声循环；故障不会自动重试；用户可Stop结束，或主动设置有限累计额度；必要时选择保守模式并使用按钮。

本候选按用户授权解除默认本机STT与累计聆听额度；TTS和每RPC时长不变。没有自动申请系统权限、识别耳机设备或增加持久音频记录。真实扬声器、耳机、浏览器AEC和物理打断延迟仍待设备验收。
