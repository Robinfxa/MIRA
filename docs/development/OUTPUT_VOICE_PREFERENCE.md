# 输出语音偏好

普通正文与已配置且获准的语音均可独立于JEV事件判断呈现。JEV仍审核可选动作/剧情/场景，未知或拒绝只保持对应变化；不再给普通speech另加输入评分。生成JSON/schema、当前上下文、Stop、播放许可、Google和记忆派生语音传输同意仍是硬边界。

页面输出静音开关会先在本地停播，再保存本会话偏好。文字与持续聆听保持可用；取消静音只影响后续输入，不恢复旧声音。保存失败会继续保持本地静音并提示，旧响应不得回滚更新的静音命令。

少量明确口令也可设置相同类型化偏好：`只打字`、`别说话`、`从现在起保持静音`在当前服务器会话内跨轮有效；`这次只打字`仅当前一轮。`取消静音`、`可以开声音`等完整明确口令可恢复后续语音。引用、否定、含糊句子或模型自身生成的文字不能自动解除静音。任意措辞不保证被识别，明确页面开关始终可用。该偏好不宣称跨服务器重启持久保存。

两条直连provider都接收实际回应模式；文字模式下语音候选会被严格拒绝，不额外再请求一次。未配置TTS或未授权Google/记忆派生语音时，解除静音不会授予这些权限。测试为合成HTTP/ASGI及编译前端验证，不证明真实声学回声、设备延迟或模型语气质量。
