# 当前采用的代码角色

2026-10-05用户确认人物暂时保持现状并接入主程序。新公开启动器`tools/live_provider.py`和`sh scripts/dev`默认使用`code-native-review`，不再要求用户额外加renderer参数。旧包、旧配置与静态图资源保留；追加`--character-renderer static-pixi`可明确回退。底层`create_app`兼容默认未变，应用集成应明确传入所选renderer。

当前语义路径几何来自1752手部/人物候选，1809整合保留静止形状并加入相机抬至胸前及放回。三套衣服、四状态、四情绪、眨眼/开口及两头饰仍独立。已认可的局部颈根在整合运动采样中保持一致。代码目录、renderer与资源摘要共同决定软件readiness；静态回退不会继承未绘制的举机能力。

本轮采用的是可继续工作的视觉基准，并非95%相似度、全部美术完成或真实设备通过。手指折角、色面和形体仍有已说明的差距；嘴型是程序状态节奏，未声称音素同步。举机不是快门操作；内置照片是原创插画，其显示回执只证明软件展示。

已执行的局部检查包括真实代码栅格输出、静止像素比对、抬起/放回与握点、三衣装四状态四情绪的眨眼/嘴型极值、以及源摘要/安装资源布局验证。最终发布仍须绑定完整同树release结果，用户设备验证单独记录。
