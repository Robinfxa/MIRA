# 代码绘制角色审阅入口

当前采用版将可编辑矢量语义部件接入现有页面，不把参考PNG作为角色绘制输入。画布为288×408，背景复用现有资源。2026-10-05用户选择暂时采用1752人物；1809整合保持其静止像素并接上举机/放回，保留已认可的局部颈根。整体精度、自然程度与设备表现仍须实际验收，源目录保留`code-native-review`技术名称以兼容旧配置。

## 单入口

依赖已经安装后，零模型离线启动：

```sh
sh scripts/dev
```

这会显示实际代码角色和九个离线固定示范按钮：三衣装、四情绪、两头饰。按钮通过原Actor与严格fixture审核，再走绘制/回执路径，没有调用模型；它不是自由对话，也不保证旧样例每个表情/转头动作在新绘制中可用。未实现的外形不会只改文字标签并回执成功。

已自行完成直连配置与独立登录的用户可继续使用[直接服务快速指引](DIRECT_PROVIDER_QUICKSTART.md)的原check/serve命令；新启动器默认采用当前代码角色。启用作者剧情仍需：

```text
--story
```

不需要 Codex CLI。check 只检查配置、所选 renderer 和实际请求字节上限，不发模型请求、不创建本机配对或打开记忆库。serve 才启动所选服务。真实模型、JEV/Google仍受原来的显式配置、内容/计费同意及有限次数约束，没有自动付费备用线路。

## 当前可见能力

- 3套独立路径服装：黑夹克、保留奶油色内搭、琥珀雨衣。
- 待机/倾听/思考/说话映射至代码局部运动。眨眼/开口由代码控制；说话是状态节奏，未按音素或真实音量同步。
- 平常/戒备/开心/娇羞以独立眉眼嘴几何绘制；相机头饰与银色星星发卡可替换。相机可从腰前抬至胸前并放回；不代表按下快门或真实拍照。其他旧版转头/放低姿态仍依实际能力目录决定，未实现的值保持unavailable。
- 内置`trip_photo`是已有原创海岸灯塔插画，展示后可立即关闭；它不是新拍或用户照片。模型与审核分别获知历史展示和当前是否可见。
- 实际准备、当前许可复核、同步绘制、DOM更新、呈现回执保持顺序。Stop闭嘴并阻断迟到帧；保持已呈现衣服历史。Close释放循环；隐藏/减弱运动停止动画。

公开目录 `apps/web/public/scene/code-native/readiness-catalog.json` 将已实现 geometry 标为 review_only。只有明确选择该审阅 renderer 后，服务端才把它映射为软件可绘制；这不是用户美术认可。目录版本与源文件摘要绑定；每次真实显示仍需客户端成功回执。

## 连接与草稿

文字输入不再被整个fieldset锁死。连接前可写草稿，发送/语音等待连接成功；失败保留草稿，显示可定位的安全错误和手动重试。一次只运行一个重试，不自动踢走其他会话。任意原始异常或返回体不会展示为诊断。

## 证据范围

已在实际模块、编译后的客户端/控制器、ASGI、SQLite和打包资源上做合成验证。真实浏览器绘制、设备声音、造型质量、性能与新直连回复仍单独验收；最终整个候选是否通过，以本包START-HERE及固定源码摘要为准。

正式应用同步画出目标情绪后回执；审阅器中的平滑emotion插值尚未接入正式完成回执，不能用插值起点假称目标已完成。局部呼吸/发束/眼嘴运动持续受当前phase和Stop控制。

通用invalid_response错误现不猜测生成或审核阶段；安全诊断可记录generation的固定阶段、HTTP状态和响应类型分类，不保存内容、header、token或任意异常字符串。HTTP200不等于模型内容有效。
