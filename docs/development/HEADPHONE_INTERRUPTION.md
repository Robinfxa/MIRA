# 耳机插话与恢复补充

这项功能只改变本机连续对话的打断和草稿恢复方式。现有服务、麦克风授权、
TTS预算、每RPC时长及静音偏好不变；共享STT及累计聆听默认不限，使用量仍如实累计。

## 选择播放方式

在“自然对话”区域开始前选择：

- **语音插话开启（建议耳机）**是默认方式。持续声音活动约160毫秒后可提前打断回应；即使声音较轻、早期检测没有触发或提前停止没有成功，完整话语仍会在正常安静和最终转写后尝试自动发送。播放和采集重叠本身不要求手动确认。发送先本地停止旧回复，再等待精确提交确认；麦克风保留。
- **保守模式（重叠语音手动确认）**是显式备用选项。播放重叠的转写保留供核对，可以使用“打断回应，继续听我说”及手动发送按钮。

声音能量不能证明说话者是谁；建议耳机，但没有检测设备或声源身份。噪声、漏音或残余回声仍可能触发。用户可随时Stop；故障及主动选择的有限额度耗尽后不会自动重开。默认没有累计次数限制，Google识别持续产生用量；次数限制或快速误触发暂停都不等于解决声学回声。
新版初始化覆盖未经标记的旧表单值，只有本版明确选择的保守偏好会保留。模式在一次麦克风聆听期间固定；先停止、切换，再点击开始。切换本身不会打开麦克风。

“聆听方式与隐私说明”内仅显示浏览器是否支持、是否报告开启回声处理。
显示开启不证明回声已经消除，不会自动替用户选择耳机模式。没有读取或展示设备名称、
设备ID等身份信息。该状态是本机临时状态，停止后清除。

延迟、重复、断序或不合法的采样不能触发自动插话；该次自动插话不可用时会显示说明，
仍可使用打断按钮。这不影响默认模式按正常停顿提交完整最终转写。已消费区间、同句修订、继续说话造成的过期分句及新请求取代的旧来源仍受原有隔离检查。

## 暂缓文字仍属于哪次请求

播放期间暂缓的语音在采集时记录其确切本机会话和请求来源。把它放入空文字框时，
页面显示它仍是被打断请求的补充；可以核对、修改，然后发送。这个发送属于人工核对
的文字，不伪造识别服务的提交证明。选择“改为新话题”会明确取消关联。

停止旧回应不等于换话题。Stop会取消旧的等待、发送和输出；之后由用户新点击发送的
已恢复补充，仍可引用同一个原请求。已经自然播完或仅静音，也不删除此前确定的来源。
已知尚未派发的历史保存失败会保留草稿来源，重试仍须通过原来的事实保存屏障。
服务明确回复本次输入尚未接受、仍在等待历史保存时，也保留来源供一次新的人工点击；
这不同于发送结果不明，不会触发自动重试。

如果已有更新请求真正派发、会话关闭，或来源缺失/混合，则不会猜测新的父请求。
请求结果不明也不会自动重发。原来接受的用户输入、确实显示过的文字及软件测得的
播放进度继续保留；未播放的计划不等于已经听见。

“手动发送当前稳定文字”可在持续聆听中使用。把暂缓文字恢复到普通输入框再发送，
当前会结束这一条持续聆听；如需继续，请再次点击开始。两条路径都不会自动获得新的
数据分享或服务调用授权。

## 验证范围

本切片使用合成PCM、实际编译页面/控制器、可控传输和本地ASGI验证。独立证据和
最终release记录绑定具体源码快照。它们不能证明真实耳机/扬声器噪声表现、实际
浏览器AEC质量、物理听见或模型语义效果；这些仍需设备验收。
