# 后台图片与自然完成提示

图片的一次已接纳任务与普通回复分开。继续发文字、可靠最终语音、只打断回应不会取消正在生成或读图的图片。原会话、请求、规格、披露依赖、政策和实际像素绑定保持不变；新的输入只撤旧展示许可。合格图片在当前轮模型决策后取得新的唯一许可，不重新生成或重新读图。旧资源请求和旧回执不能借用新许可。

图片状态是 pending / generating / reviewing / qualified / presented / held / failed / cancelled，进入同一个 story_images 上下文。qualified 只表示合格，实际 renderer 完成并保存匹配回执后才是 presented。无关回复失败不会丢弃合格结果；普通清理不会把图片 failed 改成 cancelled。原尺寸、PNG、透明度、字节、独立像素审核和请求预算守卫全部保留。

“关闭当前图片”绑定实际显示的 effect；“取消正在找的新图片”绑定该 job。关闭固定灯塔插画不会取消后台新图，取消新图不会收起另一个已显示的固定图。关闭已经显示的生成图保留呈现历史并停止它尚未发出的完成提示。旧版无 target 的关闭请求仅收起当前有回执的显示，不默认取消全部后台图片；all_photos 只有明确请求才生效。全局“停止全部”、会话关闭及授权/作用域撤销仍取消工作。

默认原生工具模式在当前 job 可取消时提供 cancel_story_image(request_id)。角色通过真实函数调用理解明确取消意图，应用精确匹配当前会话 job，再本地幂等取消。没有关键词/正则短语触发器；取消不调用图片服务、不退款、不自动重试。

完成事实有两条有界消费路径：

- 下一条普通回复先接收完成事件，不新增模型请求。context_consumed 只说明上下文收到事实，不说明角色已说或用户已听。
- 订阅原生工具模式可在实际显示回执或真实失败后的浏览器空隙，另发至多一次 tools-disabled 完成请求。它扣同一模型账本；失败、取消或结果未知都不自动重试。官方 API 不开放这次自主请求。Google TTS 继续使用原授权与同一请求/时长账本，不因图片通知增加额度。

前端沿用原图片准备器、许可门、字幕和音频队列。草稿、未提交 ASR、播放、未保存回执、未完成剧情动作和隐藏页面会推迟通知；现有安静检测是浏览器可观察的启发式，不保证用户语义上说完或实际听见。只打断回应后的本地许可仅允许当前生成图，不能重播原语音、正文或动作；新输入、Stop、Close仍立即封锁旧结果。

完成请求只附闭集 job 事实和已有授权上下文，不新增PNG传输或新的读图用途。模型可以自然说“我找找”；只有实际 presented 才可说“找到了，给你看看”。失败可以说“今天不凑巧，暂时没找到别的”。不能根据 brief 编造已经观察到的画面细节、道德解释或稍后一定完成的承诺。技术原因留在诊断/UI，需要时如实解释。

既有 image_readiness 诊断另含 job_state、job_event_reason、原 epoch/activity 和 completion_state。原因是闭集普通输入、明确图片取消、停止全部、关闭、作用域改变或回复打断；不导出 brief、图片字节或用户原文。通知的 requested、granted、字幕 presented 与音频完成分开记录。

本切片离线验证不等于真实设备声学、供应商资格、订阅计费结果或完整语言自然度验收。
