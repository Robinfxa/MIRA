## 已知能力界限

当前图像工具支持无人、无动物的风景与静物；人物/动物请求不能被悄悄替换。相机放低后仍由角色拿着，没有放到桌面的动画。角色是有限二维转向和分层动画，不是任意三维动作。字幕/口型节奏与真实音素同步分开评价。保存外观快照不代表聊天模型自动看到了当前舞台像素。

本地 STT/交互次数与订阅文字默认不设固定程序次数上限；Google TTS、图片与 API 的独立预算继续按启动配置生效。服务商配额、费用、单次超时和资源保护不被解除。

默认 LAN 为可信私网免配对访问：Mac 的 127.0.0.1 保留语音，手机 HTTP 后端禁用 STT／TTS，手机语音须已有可信 HTTPS。发现歧义时警告并保留本机；16 个临时浏览器会话仅为资源上限，所有入口共享预算，TTS 20 次、图片 1 任务不按设备增加。持久库保留原本机边界；可选手动配对不是 HTTP 语音授权。
