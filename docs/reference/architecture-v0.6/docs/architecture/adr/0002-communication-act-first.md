# ADR-0002 G01：交流行为主导

**状态：已确认。**  
**用户原始答复：B。**  
**对照问题：语音主导，还是允许非语音独立完成回应的交流行为主导？**

## 决定

采用B。角色回应可以由语音、动作、展示、场景变化或有依据的安静陪伴组成；不要求每次有意图表演都由一段语音带出。继续受同一个Session Actor、受控能力、执行资格和呈现证据约束。

## 直接含义

产品具备语音与同步字幕，但允许具体轮次无语音。运行反馈、无关装饰、生成失败和有意沉默不能混为一谈。TurnPlan／PresentationBeat保留，完成不能仅取决于audio_end。

## 不隐含批准

不批准独立持续导演Agent、自动剧情、周期性主动联系、生成媒体必选、G02全局许可快照、G03完整beat增量、具体完成schema或美术资产。

## 后续

回应选择权现已由G01.1选择③（ADR-0003），G02现已另行选择A（ADR-0004），G03后续另由ADR-0005确认，均不是本ADR原决定的隐含范围；无语音完成、quiet建立与保持、必需效果等细化记录在M03，保留字段提案地位。
