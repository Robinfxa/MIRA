# ADR-0004 G02：全局控制版本＋完整有效许可集合

**状态：已确认A，架构路线生效；wire与实现细节尚未冻结。**  
**用户原始答复：G02 选 A。**  
**来源：D4；发生于架构书v0.1之后，不虚构具体消息时间。**

## 1. 决定

采用同一Session Actor发放的一个全局有序控制版本，携带当前完整有效许可集合。语音、字幕、动作、镜头和媒体按集合中的精确资格与各自依赖独立执行。

逻辑载体使用既有细稿名称 `PresentationPermitSnapshot`。它替换当前授权状态，不是一次性命令列表，不是另一个状态写入者，也不要求全部模态同时开始。

## 2. 选择理由与未采用备选

此前A方案面向单角色、有限效果，目标是收敛统一撤销、乱序接收和跨模态授权状态。代价是更新时重复携带仍有效的许可条目；这些取舍来自H3提案，不是已测量的性能收益。

B方案“分通道版本＋公共撤销屏障”本次未采用；并不意味着B天然不安全或具有多个状态权威。未来确有变更需要时，应通过新ADR说明证据与迁移，不能在当前实现里暗中混入另一套独立授权语义。

## 3. 本次路线的直接约束

1. **同一权威。** 当前集合与全局控制版本由Session Actor产生；模型不发放许可，客户端只可即时收紧，不能擅自扩权。
2. **完整替换。** 更新显式保留仍合法的语音流与效果，移除不再允许的资格；不能因为新增一张图片就意外停止合法语音。
3. **不重复执行。** 集合中保留的效果不因更新而重播；执行消费状态、流身份与实际游标独立保留。
4. **本地新鲜度。** 最新控制版本不能覆盖本地新活动或明确停止锁；失效分支不能被迟到许可、结果或重连复活。
5. **按依赖执行。** 不依赖图片的台词可以先执行，依赖当前指定图片可见的讲解必须等待相应条件；就绪和历史显示过都不是当前执行许可。
6. **控制与数据分开。** 快照是当前有界授权，不携带媒体字节，不按动画帧发布；它不是跨网络、声卡和渲染设备的物理原子事务。

这些约束承接H3及V02／MIRA的既有边界，细化归M04，不创建额外模型调用链。
