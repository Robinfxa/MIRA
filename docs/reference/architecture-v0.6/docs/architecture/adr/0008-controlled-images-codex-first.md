# ADR-0008 · G06 受控图片慢路径，Codex优先与API预留

**状态：范围及接入偏好已确认；具体运行能力待验证。** 2026-10-02。

## 1. 确认来源

与ADR-0007共用D7的准确用户原话，不虚构第二次独立确认。G56R保持确认前历史；本章承接“我同意”并按Codex usage偏好修改原Image API首接入建议。

## 2. 范围裁定

常驻角色动画与受控素材是稳定基线。在线图片是受控、异步、允许失败的环境／物件／想象再现，不取得关键秘密、人物身份或现实事实权威。原生Codex订阅生图优先验证，标准API接口保留；不能取得可信产物或D-M检查时在线图保持关闭，而不是伪装成功。

生成规格通过、实际内容合格、当前可显示和真实已呈现四者分开。D-M直接读取实际图像；未审核预览不显示；通过结果不清除停止或隐藏。现场生成视频不进默认路径，离线核准短片仍可按受控资产合同使用。

缓存区分计算结果、内容检查与当前展示许可。新具体资源绑定新的接受记录，不能原地修改已审核摘要；派生图像不晋升为Canon。后端拒绝不通过换供应商规避，未知和技术失败按当前静默／披露约束反馈。

## 3. 不隐含批准

不冻结图像型号、原生Codex产物接口、D-M具体承载、额度阈值、存储和API自动支出；不开放用户私人肖像／摄像头新采集范围。没有现场视频解封，没有真实模型调用或性能达标声明。

程序化订阅生图与Codex界面手工制作素材必须分别验证／记录。后者不能冒充前者。技术路线失败只关闭相应运行能力，不改变已确定的内容和执行边界。
