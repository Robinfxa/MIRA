# ADR-0001 以语音 v0.2 为多模态控制基础

**状态：已确认的用户指定基线。**  
**来源：D0；不是新增的Grill选择题。**

## 决定

用户要求先参考GitHub ValueHermes的doc文档进行详细设计，并明确提出“以语音 v0.2 为基础的多模态控制架构”。本书采用该基础，逐项展开routine与判断逻辑改动，而不是并列拼接多套运行系统。

## 承接

保留v0.2的Session Actor、Input／Output Decision、独立来源与验证版本、分支失效、单人声仲裁、输入快照／输出FIFO及实际交付记录的设计地位。

## 不隐含批准

不代表每个provider或API已验证；不意味着所有v0.2实验默认启用；不批准移植ValueHermes投研DAG、全部数据库和子代理载体；不赋予写入ValueHermes仓库的操作授权。

## 正文落点

总书§01.1；M01、M04、M05、M07、M08。扩展合同由各G项分别裁定，不以“基于v0.2”为由回避新协议分歧。当前G02=A另见ADR-0004；G03后续独立确认见ADR-0005；G04后续由D6确认见ADR-0006，该版未决为G05–G06；现由D7后续确认。
