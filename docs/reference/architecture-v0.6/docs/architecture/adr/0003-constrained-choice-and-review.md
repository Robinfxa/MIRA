# ADR-0003 G01.1：约束前置、主模型受限选择、输出完整审核

**状态：已确认。**  
**用户原始答复：3。**  
**对应选项：③。**

## 决定

Input Decision识别边界与适用性、请求和未知项，并提供表达软建议；Actor组合作者规则、当前可靠事实与真实能力；主模型在合法范围内选择如何回应；Output Decision审核完整候选；程序拥有执行资格、实际回执提交与完成判断。

## 权力边界

前置判断不是固定的“必须讲话／必须动作”路由锁。主模型不改权限、来源、执行身份或完成条件。Output的allow不直接控制播放器。语义模型的解释仍可能错误，不因程序接受而提升成外部事实。

## 不隐含批准

不批准ResponseContract全部字段、digest算法、判断阈值、供应商API、全局许可集合、流式计划或新的常驻导演服务。本ADR本身不裁定G02–G06。后续G02=A的明确选择另见ADR-0004；G03另由ADR-0005明确确认；G04后续由D6独立批准；该次裁定时G05–G06仍未决（现由D7／ADR-0007–0008后续确认）。
