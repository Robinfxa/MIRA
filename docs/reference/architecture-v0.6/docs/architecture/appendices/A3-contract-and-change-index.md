## 3. 术语消歧

| 术语 | 本书含义 | 不等于 |
|---|---|---|
| Routine | 有触发、输入、状态转移、异步工作和终结证据的流程 | 已有同名函数、底座DSL |
| Decisions | 应用的有限语义判断职责／后端接口 | 已选定OpenAI产品或新服务 |
| 交流行为 | 要处理用户请求的一次有意回应 | 任意画面运动或加载反馈 |
| Beat | 一个可解释的交流小段 | LLM token、审核范围必定只含一beat、TTS包、物理原子事务 |
| 审核／发布范围 | 具备充分语义上下文的完整候选范围，可含多个beat | 一次网络分片、右花括号、每来一beat立即播放 |
| 计划封口 | 明确生成范围和可信流终态的收口 | EOF、模型自报完成、用户请求已全部满足 |
| 约束／软建议 | 前者收窄合法集合，后者建议表达方式 | 两者都不是执行许可 |
| 内容批准 | 某精确候选通过当前审核 | 此刻一定可播 |
| 资源就绪 | 文件／流可以被技术上使用 | 已呈现或内容合格 |
| 当前可见 | 当前展示位置符合某具体依赖 | 历史上显示过，或用户正在注视 |
| 已呈现 | 执行回执支持的工程事实 | 用户理解、满意或情感改变 |
| 暂停 | 撤销当前播放资格、可有界保留未失效工作 | 永久失效、旧许可自动可恢复 |
| 失效 | 旧分支终态，不重新获得资格 | 清除已发生历史 |
| 场景保持 | 同一合法已成立结果／预审无新语义维持 | 旧剧情续演、新素材披露、第二套许可系统 |
| 重新开启 | 绑定停止依据和当前可靠请求，授权新回应 | grant自行解锁、清除持续边界、复活旧分支 |
| 安全收势 | 预审的非语义运行态过渡 | 完成被取消原动作、跳最后一帧或新披露 |
| 安静陪伴 | 情境内建立并保持的互动方式 | 失败无响应、永久人物偏好 |
| 记忆投影 | 从来源派生、可重建的检索与摘要 | 当前边界／权限权威 |
| 来源基线 | 本次整合所依据的已有设计 | 已部署代码、供应商认证或实测 |

## 4. 本次未产出的实现物

没有新增可运行服务、供应商SDK适配代码、正式JSON Schema、数据库迁移、角色模型、音视频资产、真实调用收据、移动端录屏或测试通过记录。文档中的代码块只表示合同与流程，不伪装成可直接部署API。

下一次进入实现前，应先确定受影响的未决项与真实能力，不从本文字段名猜测不存在的函数或供应商功能。
