# A6 需求—模块—复用—工作包—验收追踪

**地位：编辑性映射。** 不增加需求、不冻结实现，不把RI相似用例当作已经覆盖原用例。需求书仍是产品数量与交付要求的来源；既定架构由A1／ADR约束。

## 1. 需求与实现对象


下表的“我们补什么”是集成工作，不是在暗示现成项目没有对应扩展点。代码路径与具体证据见后续项目章节和来源附录。B1；B2

| 需求／能力 | 优先参考 | 现成部分 | MIRA仍需补的接缝 | 落点 |
|---|---|---|---|---|
| Codex订阅调用与标准HTTP入口 | CLIProxyAPI | OAuth接入、模型执行、Responses兼容流 | 当前合同、受控配置、请求身份、无隐式付费切换 | M09；R2 |
| 原生Codex任务、结构化返回、中断 | 官方Codex App Server／SDK | 线程、事件、signal、outputSchema | 新上下文、事件筛选、G03语义范围、G04取消 | M03/M09 |
| 嵌入式多Provider客户端 | Pi的pi-ai | Codex Responses适配、事件转换与错误分类 | 只使用provider层，不挂完整coding-agent | M09 |
| Codex生图与图片编辑 | CLIProxyAPI＋官方Codex | images接口转换、真实图片提取、保存及错误路径 | 受控MediaRequestSpec、隔离、D-M、许可与回执 | M06/M09；R4 |
| D-M直接图像输入 | 官方Codex SDK／具备图像能力的API | local_image或图像输入协议 | 实际像素和约束对照、unknown、独立任务上下文 | M02/M06 |
| JEV有限判断 | TypeSafe官方接口 | state/questions与原语协议 | 中文问题集、来源与阈值、拒绝／未知策略 | M02 |
| 麦克风、STT/TTS服务适配 | Pipecat；LiveKit备选 | 音频传输、服务集成和输出生命周期 | 输入快照纪律、单一主控、真实声音能力验证 | M05 |
| 浏览器语音活动事件 | ricky0123/vad | MicVAD回调、浏览器端Silero运行 | 映射为activity而非最终语义话轮，保留首音节 | M05；R0/R1 |
| 播放分块、取消与资源释放 | Pipecat | sender、分块、stop／cancel | 本地终端许可、sample游标、设备尾部观测 | M04/M05 |
| 语音任务授权、排队、完成 | LiveKit SpeechHandle | 独立状态与事件、任务追踪 | 对齐G02而不使用它另发一套权限 | M04/M05 |
| 合成结果乱序但顺序播放 | AIRI pipelines-audio | sequence缓存、intent、播放回调 | 不跳过必要失败片段；不照搬多TTS默认值 | M03/M05 |
| 打断后按实际已听范围重建历史 | Open-LLM-VTuber | heard_response与中断历史处理 | 更细回执、partial/unknown、多模态曝光 | M01/M04 |
| 场景主视图、角色渲染 | Charivo；AIRI/OLVT作整合参考 | Renderer、Live2D及模块分层 | 原创素材、SceneRoot、受控效果适配 | M06 |
| 表情、动作、视线与口型 | Charivo render | 事件映射、RMS口型、清理逻辑 | affect持有权、muteSound、实际完成／中断回执 | M03/M06 |
| 非说话动作独立回应 | Charivo renderer＋MIRA合同 | 动作执行器 | 不以audio_end判断整轮完成 | M03 |
| 另一种3D角色资产路线 | three-vrm | Three.js上的VRM装载与运行 | 原创VRM、动作/表达映射；不是Live2D零成本替换 | M06；可选 |
| 复杂剧情作者工具 | ink／inkjs入口 | 剧本、编译及运行状态 | story意图不等于已呈现；秘密不下发客户端 | M06；可选 |
| 长期记忆的retain/recall/reflect | Hindsight | 服务、客户端和派生模型 | 只索引可靠事件，应用当前边界优先 | M01/M06 |
| 单写者FSM和事件串行 | XState；或现有异步运行时 | actors、状态机和mailbox | G02/G04状态与优先级、有界媒体队列 | M01/M04 |
| 请求、响应和故障Mock | MSW | 网络层处理器、浏览器/Node复用 | 同一MIRA流程，不维护独立演示逻辑 | M08 |
| 浏览器录制、回放和移动布局 | Playwright | 路由/HAR、浏览器驱动及诊断 | 真实设备声音验收；敏感日志裁剪 | M08 |
| 取消竞态、随机消息顺序 | fast-check | 属性生成、调度与反例缩减工具 | 表达MIRA不变量与可回放事件模型 | M08 |
| 密钥与素材来源说明 | 上游LICENSE／SDK示例 | 现成许可和运行说明 | 项目专属THIRD_PARTY、原创证明和无密钥演示 | 交付 |

**不能用上表推导“整套MIRA可以原封不动下载”。**已有的是每一层大量可复用实现；我们需要的是把它们的默认权限、时序与历史写入规则对齐。尤其是浏览器回放不等于扬声器实测，SDK完成不等于图片已显示，角色框架的会话状态不等于MIRA事实账本。
