## 0. 时间与当前切片

T0 指用户提出“剩余 50 小时”的窗口起点；本轮搭骨架已经消耗该窗口，**不会从骨架交付时重新计 50 小时**。
当前记录未核实官方绝对截止时刻，不编造精确剩余小时。所有 T+n 为同一个 T0 的累计里程碑。
50 小时是历时，不等于单个人连续 50 小时有效产出；并行工作要由一位集成负责人收口，并预留休息与失败缓冲。

FND-01 已作为继承基线，FND-02 已完成局部SDD/TDD示范。基础工程范围仍是：配置、分层、工厂、公共合同、Mock 控制闭环与示范测试。
不把这一切片标成原题完整 MVP、真实语音或 T+10 门槛已全部完成。

## 1. 交付目标

交付一段稳定、移动端优先、可持续 3–5 分钟的原创成年角色互动：
文字与麦克风输入；语音及同步字幕；可辨认四态；3 个表情、2 个非说话动作或视觉状态；
至少一次环境变化与对话触发事件；明确打断；迟到不复活；失败反馈与无私人 key 的同协议 Mock／回放。
附源码、本地启动或演示地址、README、AI_USAGE 和 3–5 分钟录屏。

题目来源：`../reference/architecture-v0.6/` 内 REQ 来源及总书；原题第1–3页为核心体验，第5页为交付，第6页允许如实记录未完能力。

## 2. 范围与优先级

| 等级 | 本窗口范围 | 不以什么代偿 |
|---|---|---|
| P0 | 场景 UI、原创角色、文字／麦克风、语音／字幕、多轮、四态 | 不能只交架构文档或聊天列表 |
| P0 | 3 表情、2 非说话表现、环境变化、内容触发受控照片 | 固定计时器播放不算内容触发；示例模型不算原创 |
| P0 | G02 最小完整集合、G04 本地制止／因果新请求、呈现历史 | 不能用仅取消 HTTP 代替终端停止；不把整轮生成当已呈现 |
| P0 | 同协议 Mock、超时／断线／音频／媒体基础失败反馈 | Mock 不能冒充真实模型链路；失败不能冒充安静回应 |
| P0 | 可重复启动、录屏、README、AI_USAGE | 最后一天不能继续无限加功能 |
| P1 | Codex usage 优先的真实 LLM 承载；受控生图慢路径 | 基础 live LLM 是 P0 闭环所需，订阅 carrier 选择与在线生图是可替换／扩展 |
| P1 | JEV 中文与真实判断适配验证 | 不能因赶工取消 Output Decision，或让固定规则批准任意 live 内容 |
| P2 | Hindsight 部署、跨会话成长、自动 VAD／附和／语义恢复、现场视频 | 接口和边界保留，本窗口不把它们压入关键路径 |

**对上一条口头建议的边界澄清：**“JEV 未接通就走确定性路径”只适用于固定已审 fixture 和本地控制，
不是授权绕过已确认的语义审核。必要审核不可用，任意 live 内容不发布；启用替代后端需明确路线与验证。
“订阅不稳就切 API”也不是默认付费许可；只有用户明确允许相应费用与凭据范围时才切。

## 4. 并行职责与共享写面

前端／资产线负责执行器与移动表现；后端／语音线负责输入、模型、TTS与取消；
集成负责人拥有 wire schema、装配入口和状态规则，测试线从首日维护负控。
同一时刻只有一个 owner 修改 `entrypoints/http/schemas.py`、`domain/transitions.py` 和 `bootstrap/`。
禁止多 Agent 各自搭第二个会话、播放仲裁或配置系统。工作包可并行，核心合同变更必须集中评审。

## 6. 核心演示路径

名字与不拍照边界→放低相机→用户接受照片→照片出现→解释中按住说话→
旧声音／字幕／动作停止，照片保留→新问题基于真实已呈现内容得到回应→
注入一次可恢复失败→应邀安静听雨。路径允许不同输入与拒绝，不是预定时间轴。
