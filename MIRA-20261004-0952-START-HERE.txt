Restore and rehearse
Keep the three ZIPs, this manifest, this file, the restore helper and SHA list together in one directory. From that directory run:

  # Linux checksum command:
  sha256sum -c MIRA-20261004-0952-SHA256SUMS.txt
  # macOS alternative (use this instead of the Linux command):
  shasum -a 256 -c MIRA-20261004-0952-SHA256SUMS.txt
  python3 MIRA-20261004-0952-restore.py restore --delivery-dir "$PWD" --target "$HOME/mira-0952-restored"
  cd "$HOME/mira-0952-restored"
  python3 -m ensurepip --version
  python3 tools/bootstrap.py
  sh scripts/dev --profile rehearsal
