# MIRA stage checkpoints

This repository stores explicitly authorized MIRA source backups and development-stage checkpoints. Checkpoint branches may contain unfinished work and are not releases. Each publication records its source, included/excluded scope, and verification limits. Private credentials, runtime state, dependencies, raw private source documents, and machine-specific logs are excluded. Updates never require a force push.

The imported foundation baseline is being published to main; the 2026-10-03 integration snapshot will be a separate clearly labeled WIP branch. No live-provider test, deployment, or CI success is implied.
