# Default trusted Wi-Fi access, preserved local voice

Base: optional trusted-LAN candidate with refreshed chapter source pins, restored from public manifest only. One writer owns HTTP/bootstrap/session/CLI/frontend; isolated helper supplies tools/lan_discovery.py. Lanes: providers/http/web/architecture/config/continuous, shared container/session consumers; final affected gate required. Synthetic providers/config and interface fixtures only. No paid calls, real Mac, network settings, credentials or phone acceptance.

### DEFAULTLAN01-001
Ordinary live serve discovers exactly one active physical RFC1918 LAN address and exposes exact localhost plus that LAN address, no manual pairing. Zero/multiple/unsupported automatic discovery prints an explicit LAN-disabled warning and preserves loopback, with explicit-bind or loopback-only guidance; an invalid or failed explicit bind still fails. Explicit memory/story/conversation persistence remains loopback single-operator unless incompatible LAN arguments explicitly request otherwise and fail. check performs no interface discovery and declares address selection deferred until serve.

### DEFAULTLAN01-002
The same shared app/runtime/provider budgets serve both sockets. Every browser gets independent origin-bound ephemeral ownership, at most 16 concurrent identities as a resource bound, recycled on expiry or explicit exit. Paired mode remains explicitly available with two private one-use code files. No wildcard/public bind, persistence sharing, hidden provider retry or budget increase.

### DEFAULTLAN01-003
The actual accepting socket chooses local/private trust. LAN HTTP has text-only capabilities, no speech/STT port in its Actor, no way to upgrade by response preference, and no voice HTTP/WebSocket routes. Forged Host/Origin, valid local cookie or local session token cannot turn the LAN socket into local voice. Existing localhost --voice keeps original admitted voice ports; explicit trusted HTTPS retains the existing single TLS listener.

### DEFAULTLAN01-004
All sockets are bound before starting the one shared lifespan. A bind failure closes every reserved socket and starts no runtime. Refresh, restart, third and additional browsers, foreign session tokens, stop, and current chapter asset readiness are checked against final source. Real device/certificate/provider quality remains pending.
