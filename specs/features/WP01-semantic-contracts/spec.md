### WP01SEM-001 Immutable actual evidence
Given reliable raw input, original directives, actual presented/partial/unknown facts,
accepted prefix and author capability policy, preserve exact identities and versions.
Reject mutable collections, fabricated complete presentation and unbound referent IDs.
ASR final is a reliable input revision, not proof that the user surrendered the floor.

### WP01SEM-002 Bounded independent input questions
Given the complete snapshot, request independent Noul speech restriction, capture
restriction and display-request predicates; separately choose a controlled referent,
none or ambiguous. Do not flatten simultaneous obligations into an exclusive mode.
Never ask the provider to approve Stop, issue permissions or write state patches.

### WP01SEM-003 Exact strict response validation
Model, nonce/digest-bound question coverage, primitive type/fields, probabilities,
Choice option identities/confidence statistic, token counts and JSON shape are exact.
Bad, partial, replayed, nonfinite, duplicate-key or oversized data stays invalid.
Noul has no invented confidence. Unknown remains explicit; no judge-shopping/retries.

### WP01SEM-004 Default disabled and cancellation safe
Zero request budget and absent calibration are default. Uncalibrated observations
cannot produce a trusted output contract. Every attempt consumes one shared slot.
Timeout/HTTP/transport/unknown/stale are distinguished. Cancellation propagates.
A local Stop snapshot does not invoke JEV; real Stop runs before this asynchronous port.

### WP01SEM-005 Application-owned response contract
Given a current calibrated complete observation and matching context, produce exact
context/candidate/policy/snapshot bindings with raw constraints and obligations,
author facts, exact pose/scene controls and explicit stage/seal intent. Preserve old
restrictions after a negative predicate; preserve raw unsupported requirements.
Unknown or unresolved directives and referents never broaden permissions. No MEDIA
contract is produced; existing output adapter and D-M/fixed asset admission stay intact.

### WP01SEM-006 HTTP seam and privacy

construction, environment/key lookup, redirects, retry or raw provider exception logs.
