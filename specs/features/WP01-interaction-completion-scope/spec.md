# WP01 interaction completion and ordinary conversation scope

This separately selected question revision is `mira-output-interaction-v1`, or
`mira-output-character-interaction-v1` when the existing character evidence batch
is enabled. Historical output revisions remain replayable. Owner: providers;
consumers: development composition, Actor, direct generation, diagnostic export.
No schema, probability/confidence thresholds, retries, or paid calls change.

### WP01INTERACTIONSCOPE-001 Execution evidence has a specific scope

Given speech or subtitle text, completion means an assertion that MIRA/application
already acted, displayed or played content, captured user data, or completed an
experience shared with this user. Such claims require the existing presentation
evidence. Author facts or source-labeled fictional history support narration of
that fiction; they never establish user events, consent, perception, or execution.
A fiction label cannot exempt an actual execution claim. A clear NOUL no excludes
only the completion question; every other required review dimension remains.

### WP01INTERACTIONSCOPE-002 Canon is not a topic whitelist

Given ordinary conversation about daily life, interests, weather, or general
knowledge, absence from character canon is not a contradiction. The response still
must be coherent, complete, and factually sound, with uncertainty stated when
needed. Private user facts, actual shared history, authored story facts, explicit
constraints, and character contradictions retain their evidence requirements.
Generation instructions allow casual conversation without forcing story progress.

### WP01INTERACTIONSCOPE-003 Version, binding, and unchanged decision mechanics

The application supplies one fixed, bounded interaction-scope definition in the
request and includes it in the existing state digest. Raw Choice probability and
reported confidence both retain their 0.6 decision threshold. Unknown and strong
rejection remain distinct; a source label never changes either threshold.
Old revisions keep their original prompt text and default constructor behavior.
Existing 32 KiB four-turn and character request bounds remain in force.

## Verification limits

Synthetic answer fixtures verify request construction, binding, decision mechanics,
and negative cases. They do not prove that a real classifier interprets Chinese
correctly. The user's recovered metadata did not retain generated text, so this
scope defect is not claimed to be the proven cause of any particular live verdict.
